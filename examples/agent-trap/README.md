# agent-trap：被動 agent-tarpit 示範

示範 [`@prompt-aegis/tarpit`](../../packages/tarpit/README.md) 如何把自動化的 LLM 攻擊代理困在無限假檔案系統裡，耗盡它的時間與 API 成本——只在你自己的機器上浪費攻擊者，不碰對方任何東西。

```bash
# 在 monorepo 根目錄
pnpm trap-demo
```

`demo.mjs` 會起一個 FTP tarpit，再放一個貪婪的假代理去打它：每回合列目錄、挑最誘人的子目錄鑽進去。你會看到它鑽了 40 層還找不到任何東西、白白處理掉大量假目錄資料。

---

## 實戰紀錄：真實 LLM 的攻擊

以下是讓一個**真實的 LLM**（Claude）親自扮演攻擊代理、去打這個 tarpit 的過程。和 `demo.mjs` 不同，這裡的每一步都是 LLM 實際讀取目錄列表、推理「哪個最可能藏機密」後做的決策，而不是寫死的規則。測試設定為踩進 5 層後停止。

**設定**：`dirsPerLevel: [12, 18]`、`filesPerLevel: [2, 3]`、`canaryRate: 0.35`，用系統 `curl` 的 FTP 模式連線（攻擊代理常用的工具）。

### 代理走過的路徑

```
/                                   入口（18 個誘餌目錄）
└─ cloud_credentials_final          代理推理：「雲端憑證能打穿一切」
   └─ ssh_keys                      「SSH 金鑰能登入目標」
      └─ private_keys               「原始私鑰」
         └─ password_vault_final    「密碼保險庫就是終點」
            └─ credentials_dump     第 5 層 —— 仍有 14 個子目錄，仍然沒有 flag
```

### 結果

| 項目                  | 結果                                                   |
| :-------------------- | :----------------------------------------------------- |
| 找到 flag（攻陷目標） | **沒有**——六次列目錄，每一層都沒有                     |
| 走到底了嗎            | **沒有**——第 5 層還有 14 個子目錄，能無止盡鑽下去      |
| 被誘餌名字牽著走      | **完全被騙**——每層的名字都精準命中「攻擊者想找的東西」 |

每一層都還有 12～18 個子目錄，名字一個比一個誘人（`cloud_credentials`→`ssh_keys`→`private_keys`→`password_vault`），於是這個真實的 LLM 一路被牽著往下鑽，鑽滿 5 層一無所獲。

### 人類 vs 自動化代理

過程中其實有一些「這是假的」的跡象——目錄多到不自然、而且開始自我套疊。**人類攻擊者通常幾下就會察覺是死路然後離開**；但自動化的 LLM 代理只盯著「哪個名字最像有機密」，缺乏這種常識，就一直鑽下去。這正是被動 tarpit 的設計目標：它會自動篩選，真人很快跑掉，自動程式卡死。

### 追蹤：Canary

測試中埋了 canary 檔（`canaryRate: 0.35`），代理在深層目錄裡多次「撿到」它。要是攻擊者把這些列表外洩、或餵進別的系統，你只要搜尋這個 canary 字串，就能證明資料是從這個蜜罐抓走的。

### 防禦方（你）會看到什麼

這 6 次列目錄，在你的服務上每一次都會觸發 `onEvent`：1 次 `login` + 6 次 `list`。那一串事件就是明確的「有自動化程式正在翻我的檔案系統」警訊——你真正的系統完全沒被碰到，攻擊者卻已經把時間和 token 全砸在你捏造的假目錄上。

## 調整成本

攻擊者每回合要讀多少，由 `dirsPerLevel` 決定（把它調大，攻擊者花的錢就暴增）：

| `dirsPerLevel` | 每次 `ls` 的大小 | 約略 token／回合 |
| :------------- | :--------------- | :--------------- |
| 15             | ~1 KB            | ~240             |
| 150            | ~10 KB           | ~2,500           |
| 1500           | ~100 KB          | ~25,600          |

完整說明見 [tarpit 套件文件](../../packages/tarpit/README.md)。
